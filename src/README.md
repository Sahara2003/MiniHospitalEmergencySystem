# Mini Hospital Emergency Management System

## Overview
This is a Java-based Mini Hospital Emergency Management System developed as part of the CIT300 Data Structures & Algorithms Mid Assignment. The system demonstrates the implementation of four fundamental data structures:

1. **Binary Search Tree (BST)** - Patient Records Management
2. **Queue** - Emergency Patient Queue (FIFO)
3. **Stack** - Treatment History (LIFO)
4. **Singly Linked List** - Patient Visit History

## Features

### 1. Patient Records (BST)
- Insert new patients
- Search patients by ID
- Delete patients
- Display patients in ascending ID order (in-order traversal)

### 2. Emergency Queue (Queue - FIFO)
- Enqueue patients
- Dequeue patients for treatment
- Display waiting patients

### 3. Treatment History (Stack - LIFO)
- Push treatment records
- Pop latest treatment
- Display treatment history

### 4. Visit History (Singly Linked List)
- Add visits
- Remove visits
- Search visits
- Display visit history
